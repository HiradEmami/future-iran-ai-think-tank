# Contributing to Future Iran AI Think Tank

Thank you for your interest in contributing to the Future Iran AI Think Tank project.

This project is a long-term, community-driven initiative focused on exploring how artificial intelligence, robotics, data science, and automation can contribute to solving real-world problems and building better systems for the future.

We welcome contributions from engineers, researchers, students, entrepreneurs, and anyone interested in technology, infrastructure, education, and future-oriented problem solving.

---

## Before You Start

Before contributing, please:

- Read the README.md
- Check existing documents to avoid duplicates
- Open an Issue if you want to propose a large new topic
- Keep documents structured and technical
- Make sure your contribution aligns with the project goals

---

## Ways to Contribute

You can contribute in many ways, including:

- Writing about major problems and challenges
- Proposing AI or technology-based solutions
- Writing research ideas and technical directions
- Suggesting infrastructure and technology strategies
- Writing education and workforce development proposals
- Adding case studies from other countries
- Improving documentation and structure
- Reviewing and improving existing documents
- Participating in discussions and brainstorming
- Proposing project ideas or startup ideas

You do not need to be an expert to contribute.  
Clear thinking, structured writing, and constructive ideas are highly valuable.

---

## Writing Guidelines

When adding a new document, try to follow this structure where applicable:

1. Problem Description
2. Why This Matters
3. Current Situation
4. How AI / Technology Can Help
5. Required Data
6. Required Infrastructure
7. Challenges
8. Potential Impact
9. References (if available)

Clear, structured writing is preferred over long unstructured text.

## Contribution Workflow (GitHub)

To contribute to the repository, please follow the standard GitHub workflow:

1. Fork the repository
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Commit your changes
6. Push your branch
7. Open a Pull Request
8. Wait for review and discussion
9. After approval, your contribution will be merged


```bash
git clone https://github.com/YOUR-USERNAME/future-iran-ai-think-tank.git
cd future-iran-ai-think-tank
git checkout -b my-contribution
# make changes
git add .
git commit -m "Add document about AI for water management"
git push origin my-contribution
```
Then open a Pull Request on GitHub.

## Pull Request Template
You can use the following template for the pull request:

```markdown
## Idea Title
[Name of the idea]

## Summary
Provide a short summary of this pull request.

## Changes
Describe what was added, updated, or removed.

## Section
Where does this contribution belong?
- [ ] Idea Proposal
- [ ] Accepted Idea
- [ ] Project
- [ ] Knowledge Base
- [ ] Report
- [ ] Documentation
- [ ] Templates
- [ ] Other

## Reason
Explain why this contribution is useful or important.

## Additional Notes
Any additional information for reviewers.
```

## Contribution Principles

When contributing to this project, please keep the following principles in mind:

- Focus on real-world problems
- Focus on technical and engineering solutions
- Think long-term
- Be constructive and solution-oriented
- Avoid political debates and ideological discussions
- Support ideas with reasoning, data, or examples
- Be respectful and professional
- Write clearly and structurally
- Collaborate and improve ideas together

This project is about building ideas and knowledge, not winning arguments.
