# Security Policy

---

## Overview

Although this repository does not primarily contain production software, we take security and responsible disclosure seriously. If you discover a security vulnerability related to this repository, its infrastructure, or any associated tools, please report it responsibly.

---

## Reporting a Vulnerability

If you discover a security issue, please report it privately instead of opening a public issue.

You can report security vulnerabilities by contacting the project maintainers through one of the following methods:

- Open a private security advisory on GitHub
- Contact the maintainers via email (if available)
- If no private channel is available, clearly mark the issue as a security issue

Please include the following information when reporting a vulnerability:

- Description of the vulnerability
- Steps to reproduce the issue
- Possible impact
- Suggested fix (if any)

We will review the report and respond as soon as possible.

---

## Responsible Disclosure

We ask that you:

- Do not publicly disclose the vulnerability before it has been reviewed
- Give maintainers time to investigate and address the issue
- Avoid exploiting the vulnerability beyond what is necessary to demonstrate the issue

---

## Scope

This security policy applies to:

- Repository content
- Templates
- Scripts
- Documentation infrastructure
- Any automation related to this repository

---

## Acknowledgements

We appreciate responsible security disclosures and the efforts of contributors who help improve the safety and reliability of this project.
