# Idea Proposals

---

This folder contains early-stage ideas and proposals related to AI, technology, infrastructure, education, and national development topics.

Ideas in this section are **not yet approved or started as projects**. They are proposals that need discussion, research, feasibility analysis, and review before moving forward.

---

## Purpose

The goal of this folder is to:
- Collect new ideas
- Encourage discussion and brainstorming
- Document potential solutions for national and technological challenges
- Evaluate feasibility and impact before starting projects

---

## What should go here

Examples:
- New AI initiatives
- Startup ideas
- National infrastructure proposals
- Education reform ideas
- Research initiatives
- Technology policy ideas

Each idea should be written using the **idea template** from:

[templates/idea-template.md](/06-templates/01-idea-template.md)

---

## How to Submit an Idea

To submit a new idea:

1. Fork the repository
2. Create a new file in this folder
3. Use the idea template
4. Name the file clearly (e.g., `smart-water-management.md`)
5. Open a Pull Request
6. The community will review and discuss the idea

---

## Idea Lifecycle

Ideas typically move through the following stages:

1. Idea Proposal → (this folder)
2. Accepted Idea → 02-accepted-ideas
3. Project → 03-projects
4. Report / Results → 05-reports

---

## Goal

This folder should become a large collection of structured ideas that can later turn into real projects, policies, companies, or research programs.
