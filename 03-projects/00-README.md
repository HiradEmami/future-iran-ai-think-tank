# Projects

---

This folder contains active and planned projects derived from accepted ideas.

Projects are concrete initiatives that include:
- Clear goals
- Defined scope
- Implementation plan
- Timeline or roadmap
- Technical or organizational work

---

## Purpose

The goal of this folder is to:
- Document ongoing projects
- Track progress
- Store project plans and documentation
- Provide structure for implementation

---

## What should go here

Each project should include:
- Project description
- Goals and impact
- Technical approach
- Required resources
- Timeline
- Risks and challenges
- Expected outcomes

Use the project template:

[06-templates/02-project-template.md](/06-templates/02-project-template.md)

---

## Project Flow

Ideas typically move through this pipeline:

Idea → Accepted Idea → Project → Report

---

## Goal

This folder represents the **execution layer** of the organization — where ideas become reality.
